# Katalog Solusi APPIK — v1

Sumber data utama: [data/industries.json](../data/industries.json). Website: [index.html](../index.html).

## Aturan global

- A: Paket Lengkap; software saja jika perangkat kompatibel dan fungsi memungkinkan
- B: Software Only atau Paket Lengkap; platform sesuai kebutuhan dan ketersediaan
- C: Awasi BOX (paket lengkap) atau Awasi AI Video Analytics (Software Only, PC dan CCTV kompatibel); konsep belum teruji
- D: AI TinkerBox — paket perangkat, sensor, software dan konfigurasi; bukan Software Only
- E: Custom Integrated System; paket sesuai komponen
- Status portofolio mengikuti produk aktual; penawaran industri bersifat custom.
- Platform Android, Desktop, Web sesuai kebutuhan; bukan produk duplikat.
- Grid desktop 4 kolom, HP 2 kolom; tautan #industri/id; WhatsApp konsultasi dan berbagi.
- Tidak menawarkan instalasi LAN/internet atau perangkat lepas.
- AI/IoT merupakan rencana custom, perlu uji kelayakan; bukan pengganti sistem keselamatan bersertifikat.
- Jaga privasi dan akses data, khususnya anak dan pasien.
- Perangkat di area berbahaya harus memenuhi standar keselamatan.
- Wisata & Rekreasi: rincian awal, belum ditinjau satu per satu.
